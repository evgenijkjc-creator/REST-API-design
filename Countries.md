# GET /api/v1/countries — Получение справочника стран



Метод: GET

URL: /api/v1/countries

Пример запроса:

GET https://{domain}/api/v1/countries

Назначение:
Получение списка доступных стран для заполнения поля «Страна» в форме регистрации пользователя.

# Request

Request Body: отсутствует.

Query Parameters: не предусмотрены.

Content-Type ответа: `application/json`

# Успешный ответ

HTTP Status: 200 OK

Response Body:

```json
{
  "data": [
    {
      "code": "RU",
      "country": "Россия"
    },
    {
      "code": "BY",
      "country": "Беларусь"
    }
  ]
}
```

# Описание параметров ответа

| Параметр       | Тип данных | Описание                 |
|----------------|------------|--------------------------|
| data           | array      | Массив доступных стран   |
| data[].code    | string     | Двухбуквенный код страны |
| data[].country | string     | Название страны          |


# Обработка ошибок

Некорректный запрос.

```json
{
  "message": "Некорректный запрос"
}
```

Пользователь не авторизован.

```json
{
  "message": "Требуется авторизация"
}
```

```json

}
```
#500 Internal Server Error
Внутренняя ошибка сервера.

```json
{

}
```

# Логика работы API

1. Пользователь открывает страницу регистрации.
2. Клиентское приложение отправляет GET-запрос на /api/v1/countries.
3. Сервер обрабатывает запрос и получает список доступных стран.
4. Сервер возвращает HTTP 200 OK и массив стран в формате JSON.
5. Клиентское приложение отображает полученные страны в выпадающем списке.
6. Пользователь выбирает страну.
7. При отправке формы регистрации код выбранной страны передаётся в поле `country` запроса `POST /api/v1/register`.

#Связь с другими API

Связанный эндпоинт: `POST /api/v1/register`

При регистрации пользователя значение поля `country` должно соответствовать одному из кодов, полученных из справочника стран.
Пример:

```json
{
  "country": "RU"
}
```

# Требования к API

- Передача данных осуществляется по HTTPS.
- Ответ сервера возвращается в формате JSON.
- Каждый объект страны содержит код и название.
- Коды стран должны быть уникальными в пределах справочника.
- При успешном запросе сервер возвращает HTTP 200 OK.
